# XSS via XML document

This repo showcases how to exploit XHTML namespace rendering by modern day browsers to lead to XSS.

# How to run this

1. XML Files - Simply open them in your chosen browser.
2. Simple Webapp CTF - Run this `python3 server.py`. Then, go to `http://localhost:8000/` with your browser.

# Other notable methods
- XSS via SVG.
